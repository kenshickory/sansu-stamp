# さんすうスタンプ

小学1〜2年生むけの算数ドリル。HTMLファイル1個で動きます。
サーバーもデータベースも使いません。進捗はそれぞれの端末のブラウザに保存されます。

- 作り方の記録 … https://kenshickory.github.io/sansu-stamp/making-of.html

## 自分で改造するには

1. このリポジトリをダウンロード（または `git clone`）
2. そのフォルダで Claude Code を起動する

   ```bash
   cd sansu-stamp
   claude
   ```

3. 日本語で頼む

   > index.html が算数アプリです。九九を最初からONにして、
   > あと「たしざんめいじん」みたいな称号を追加して

4. うまく動いたら、その状態を保存する

   ```bash
   git add .
   git commit -m "九九を最初からONにした"
   ```

   Claude Code に「いまの状態でコミットして」と言うだけでも保存できます。

### 壊れたとき

最後にコミットした状態まで戻します。

```bash
git checkout -- .
```

くわしい進め方は [making-of.html](https://kenshickory.github.io/sansu-stamp/making-of.html) の
「08 引き継ぎ」「09 保険」を読んでください。

## アプリの中身

- 1日10問1セット（問題数・セット数は「おうちの人」ページで変更可）
- まちがえた問題を翌日・3日後・7日後に自動で再出題
- 単元11個。小1の7単元が初期ON、小2の4単元（100までのかず／2けたのけいさん／九九／とけい）は初期OFF
- 正答率にあわせて単元ごとに難易度が自動で上下（3段階）
- スタンプカレンダー、れんぞく日数、おやすみけん（週2枚）、コレクション24種
- 「おうちの人」ページ（4桁の暗証番号）… 週次レポート、苦手単元、単元のON/OFF、データの引っ越し

## 注意

- 進捗は端末ごと・ブラウザごとに別々に保存されます。引っ越しは「おうちの人」ページから
- プライベートモードで開くと進捗が残りません
